Regras para conhecimento sólido

  1. Pomodoro sagrado — 40 de foco e 10 de pausa de verdade (levantar, água, nada de celular). Só o foco conta.
  2. Projeto por fase — sem projeto, não fixou. A semana de projeto não é opcional.
  3. Repetição espaçada — Anki todo dia (5–10 min) e 1 pomodoro de revisão no domingo.
  4. Teach-back — ao fim do dia, explique em voz alta ou num parágrafo o que aprendeu.
  5. Anti tutorial-hopping — termine o curso da vez antes de abrir outro. As alternativas listadas são para trocar, não para somar.
  6. Tudo no Git — todo exercício e projeto vai para o GitHub (treina Git e vira portfólio).
  7. Buffer — atrasou? empurre a semana. Nunca corte a revisão nem o projeto para "tirar o atraso".
  8. Velocidade do vídeo — 1x no conteúdo novo e difícil; 1,25x–1,5x no que já conhece. Pause e digite o código.
